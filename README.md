# Astellune 🌙
### Together under the same moon.

Astellune is a private couples' web application designed to help two people stay connected through shared conversations, memories, notes, and interactive activities.

## ✨ Features

- 🔐 User registration and login
- 💞 Private couple spaces
- 💬 Chat between partners
- 🖼️ Shared photo memories
- 📝 Personal notes
- 🎮 Interactive games
- 🔒 Space-based privacy controls
- 🚪 Secure logout

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Local Development:** XAMPP
- **Version Control:** Git and GitHub

## 🚀 Getting Started

### Prerequisites

- XAMPP
- A web browser
- A code editor

### Installation

1. Clone or download this repository.
2. Place the project folder inside the XAMPP `htdocs` directory.
3. Start Apache and MySQL in XAMPP.
4. Create a MySQL database named `astellune`.
5. Import the project's database schema, if included.
6. Configure the database connection using the example configuration provided.
7. Open `http://localhost/Astellune/` in your browser.
